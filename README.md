- Loan, customer and ledger data **never leaves the phone**. The app uses the internet only to check this page for updates and to download them. / লোন, গ্রাহক ও লেজারের তথ্য **ফোনের বাইরে যায় না**; ইন্টারনেট শুধু আপডেট দেখা ও ডাউনলোডের জন্য।
